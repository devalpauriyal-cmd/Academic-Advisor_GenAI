# Publication notes

The owner approved public publication of this ALICE snapshot, including the university materials listed in this document, on 8 November 2026.

## Repository and history

The owner selected the existing empty public repository [`devalpauriyal-cmd/Academic-Advisor_GenAI`](https://github.com/devalpauriyal-cmd/Academic-Advisor_GenAI) as the publication target. The publication copy uses a new `main` branch and a fresh initial commit. The original local working tree, existing Git history and original remote are preserved separately. See [project provenance](PROVENANCE.md) for the original repository, base commit and authorship.

## Included files

- Backend and frontend source, including the supplied uncommitted advising/context/identity changes.
- Runtime/development dependency manifests, npm lockfiles, a Python environment snapshot and safe environment examples.
- Canonical university PDFs/XLSX, processed Markdown/JSON/SQLite, semantic index and intentional backend deployment copies.
- Verified ONNX model and tokenizer, model license and attribution.
- Synthetic profiles and audio/image fixtures, existing automated tests, evaluation runners and historical measurements.
- Current README and UI screenshot, historical screenshots/report, audit, provenance, source inventory, demo walkthrough and assignment brief.

`FILE_INVENTORY.csv` records current file paths, sizes and SHA-256 checksums, excluding its own checksum. `python scripts/package_repository.py` refreshes that inventory and creates a local review ZIP without changing remotes or uploading anything.

## Excluded files

Real `.env` files, credentials, private uploads, virtual environments, installed packages, build caches, Vercel account links, local backups, browser profiles and temporary output are ignored. Redundant root document copies and unused starter SVGs are excluded. Application source and datasets were compared with the supplied working tree to verify preservation.

## Validation and limits

See [the audit](AUDIT.md) for observed tests, build/data checks and limitations. Historical evaluation files do not certify the current availability or performance of external AI services. The source documents and branding remain third-party material; approval to publish does not assign them a new license. See [data and attribution](DATA_AND_ATTRIBUTION.md).

A repository URL is treated as published only after the remote exists and its pushed commit and public visibility have been verified.
